# 完整示例：5 种变异点

这个示例包含 ai-test-check 支持的全部 5 种变异类型：

| 类型 | 位置 | 说明 |
|---|---|---|
| **运算符** | `age >= 18` | `>=` → `>` |
| **数字边界** | `>= 18` 的 `18` | `18` → `19` |
| **布尔字面量** | `isCitizen === true` | `true` → `false` |
| **状态字符串** | `code === 'active'` | `'active'` → `'inactive'` |
| **条件取反** | `if (total >= 100)` | `if (!(total >= 100))` |

## 跑一下

```bash
node test.js
# ✅ 5 个测试全部通过（但有效性只有 39%）

npx ai-test-check . --all
# 18 个变异点，7 个被杀，11 个存活
# ★ 测试有效性: 39%
```

## 结果解读

```
存活的变异按类型分组:

  边界条件（5 处）⇒ 补「等于/不等于」的情况
  数字边界（4 处）⇒ 补「刚好等于/差一」的情况
  逻辑组合（2 处）⇒ 补「只满足一个条件」的情况
```

**★ 这告诉你该补哪类测试**，而不是只给一个百分比。
